While a session is ended, its page shall offer "Copy resume command". It copies `cd '<folder>' && claude --resume <id>`, the folder single-quoted. A live session's page shall not offer it. A failed copy shows "Copy failed: <reason>. Press Copy resume command again." Screen/state: Pane Session, Ended. Tag: `@F49`.
