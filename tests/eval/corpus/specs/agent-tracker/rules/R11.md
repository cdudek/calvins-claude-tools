While a session needs you, the collector shall show a reason. It is "asks permission" when `waitingFor` matches the permission value recorded from a real waiting session at build. If the build had no waiting session, "asks permission" never shows and any `waitingFor` gives "waiting". It is "asks a question" when the question check flagged it, else "waiting". An unknown state has its own reason (F66). Screen/state: Home, Needs you row. Tag: `@F4`.
