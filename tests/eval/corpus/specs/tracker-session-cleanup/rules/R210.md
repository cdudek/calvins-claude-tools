If a code path of the tracker or the script passes a banned argument, the build fails. The banned are `--force`, `--force-remove-worktree`, `--discard-unpushed`, `-f`, `-D` and `branch -D`. A test greps both source trees. Screen/state: all. Tag: `@F64`.
