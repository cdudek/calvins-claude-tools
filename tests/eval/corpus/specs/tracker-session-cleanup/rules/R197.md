When the owner answers "Clear all N" or "Remove all N", the skill shall run `act` with that batch's ids. The script shall re-check each id right before it acts, and re-read the session list for a session. It shall act only on an id that still passes. It skips and names an id whose re-check or action fails, or that is not in a fresh `list`. Screen/state: skill, Acting. Tag: `@F59`.
