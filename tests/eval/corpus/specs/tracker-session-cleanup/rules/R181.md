The mod shall count a worktree removable only when all five conditions hold, each computed by code. (1) The session's `cwd` is a linked worktree, not the first entry of `git worktree list --porcelain`. (2) It has no modified, staged or untracked files. (3) It has no commits that are not pushed. (4) Its branch is merged into the default branch, or its PR is merged or closed. (5) No live row has a `cwd` equal to the worktree path or under it. Screen/state: Session, Worktree. Tag: `@F35`.
