If `claude rm` fails and the session is still listed, then the mod shall change nothing else and draw Clear again. It shall show "✗ Claude Code could not clear this session: <reason>. Nothing else was changed. Press Clear to try again." The reason is one line cut at 60 cells, dropped when unusable. Screen/state: Session, Failed. Tag: `@F28`.
