While a session's row in `claude agents --json` has no `pid`, the collector shall mark it ended, except this session's own (F72). This holds whatever the row's `state` or `status`. It is observed for background rows. For interactive rows without `pid` it is an assumption, and a fixture covers it. Screen/state: Home NEEDS YOU; Session header "○ ended 63d ago". Tag: `@F1`.
