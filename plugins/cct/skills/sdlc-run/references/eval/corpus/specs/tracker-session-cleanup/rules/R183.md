If a condition of F35 fails, then the Session page shall name the first failed one. An example is "Worktree login stays: it has uncommitted changes. Commit or stash them in a terminal." The other three reasons are unpushed commits, an unmerged branch and another session using it. Screen/state: Session, Worktree stays. Tag: `@F37`.
