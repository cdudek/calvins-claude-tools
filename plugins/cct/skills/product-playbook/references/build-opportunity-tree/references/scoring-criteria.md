# POC Scoring Criteria

## Evaluation Dimensions

Score each solution on three dimensions (1-5 scale):

### Feasibility
How hard is it to build/test?
- **1** = Months of work, major technical complexity
- **2** = Several weeks, significant effort
- **3** = 2-4 weeks, moderate effort
- **4** = 1-2 weeks, straightforward
- **5** = Days, minimal/no dev work

### Impact
How much could it move the target outcome?
- **1** = Minimal outcome movement
- **2** = Small improvement
- **3** = Moderate improvement
- **4** = Significant improvement
- **5** = Major outcome shift

### Market Fit
How well does it align with customer needs?
- **1** = Customers don't care
- **2** = Weak demand signal
- **3** = Some interest
- **4** = Good fit, customers would value it
- **5** = Customers actively request this

## Recommendation Format

After scoring, provide:
1. **Recommended POC** — Highest-scoring or best-balanced solution with rationale
2. **Alternative POC** — Runner-up with different tradeoffs (e.g., faster learning vs. higher impact)
3. **Not recommended** — Lowest priority with explanation of why to defer
