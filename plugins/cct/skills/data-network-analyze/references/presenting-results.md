# Presenting analysis results

Guidance kept from the retired general-analysis stub; it applies to any network or tabular result you hand to a reader.

- Format numbers compactly with one decimal: 1.2M, 345.7K, 23.4%.
- Give every metric and every number a "so what" next to the value: translate the statistic into the business consequence. The explanation style guide is the last section of the classification metrics reference (`cct:data-classification-metrics`).
- Order a written result as executive summary, key findings, recommendations.
- Present tables as well-structured markdown with units in the header.
- When data comes from several sources, say how the sources were joined and what was lost in the join.
